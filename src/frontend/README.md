# VPN Super Pro

An ad-supported VPN service built on the Internet Computer, where users unlock timed VPN sessions by watching advertisements.

## Features

- **Ad-Powered Access**: Watch a 40-second ad to unlock 2 hours of VPN access
- **Internet Identity Authentication**: Secure, privacy-preserving authentication
- **Session Management**: Track and manage VPN session time limits
- **Admin Panel**: Comprehensive administration dashboard with user management
- **User Blocking**: Admins can block/unblock users for security
- **AdMob Integration**: Configure AdMob IDs for production deployment
- **Custom Branding**: Upload custom logo for app personalization
- **Legal Pages**: Professional Privacy Policy and Terms of Service
- **Contact Support**: Direct email support integration
